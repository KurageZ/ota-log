# 电子切册筛选与规格重构 QA

对应需求：[`docs/product/cheki-filter-refactor.md`](../product/cheki-filter-refactor.md)。自动化测试通过后，按下列清单完成 iOS / Android、浅色 / 深色人工验收。

## 数据升级与备份

- [ ] 从 v20 开发数据库升级后，Item 数量、价格、收藏、备注、顺序、正反面图片及 Record 关联保持不变。
- [ ] `display_aspect_ratio` 已移除，全部旧 Item 使用“三寸竖版”。
- [ ] 新建数据库只接受五种规格，非法规格被约束拒绝。
- [ ] v8 完整备份导出和恢复正常；v7 备份恢复时忽略旧比例并使用默认规格。

## 视图与筛选状态

- [ ] iOS / Android 右上角视图设置均打开 Bottom Sheet，修改后立即生效并持久化。
- [ ] 默认进入 Item / 按艺人 / 中图 / 最新优先；Record 默认显示缩略图。
- [ ] Record 和 Item 筛选互不覆盖；切换模式、进入详情返回、离开切册后同一会话返回均保留。
- [ ] 重启 App 后筛选清空，视图设置保留。
- [ ] 日历、统计和活动详情深链强制进入 Record，只初始化 Record 条件；首页无条件进入恢复上次模式。

## 筛选交互

- [ ] Sheet 内修改不会刷新列表；只有点击“应用”后生效。
- [ ] 下滑、遮罩、系统返回关闭会丢弃草稿；重置后仍需点击“应用”。
- [ ] 日 / 月 / 年 / 自定范围均可选择；子选择器取消不修改草稿，确认后返回主筛选 Sheet。
- [ ] 单推 / 收藏艺人快捷按钮可以整批添加和整批移除，之后仍可逐个增删。
- [ ] 日期下“其他条件”直接展示、不折叠；图片状态、快捷条件和规格可分组，组间结构清楚。
- [ ] 各组 chips 在页面内换行、不横向滑动；已关联活动 / 已有备注 / 有背签（Item 另有已收藏）可再次点击取消，规格组位于最后且“全部”chip 可清除。
- [ ] “有背签”在 Item 模式只命中有背面图片的 Item，在 Record 模式命中任一 Item 有背面图片的 Record。
- [ ] 单推 / 收藏艺人 chip 位于“艺人”分区选择器上方，整批选中时呈选中态。
- [ ] 筛选角标按类别计数；多位艺人摘要显示“艺人 N 位”。

## 数据口径

- [ ] Record 图片状态按完整 quantity 计算无图、部分和完整。
- [ ] Record“已有备注”匹配 Record 备注或任一 Item 备注。
- [ ] Item 模式只显示有图 Item；规格、备注、收藏必须命中同一 Item。
- [ ] Item“已有备注”不因所属 Record 有备注而命中。
- [ ] 精确活动存在时只显示“活动：活动名”，不重复显示“已关联活动”。

## 规格与视觉

- [ ] 新建 Record 默认三寸竖版；编辑 Record 的新增规格不覆盖旧 Item。
- [ ] Item 编辑页高级信息可切换五种规格，没有自定义入口。
- [ ] Record 详情显示规格分布；全屏详情显示当前 Item 规格。
- [ ] Record 列表、按艺人和相册视图不显示规格文字或徽标。
- [ ] 三寸、五寸横竖版和方形缩略图均完整显示、不裁切；Record 详情保持三列且允许规格决定缩略图高度，其他切册网格保持稳定、不变为瀑布流。
- [ ] 浅色 / 深色文字对比可读，动态文字不溢出，触控目标不低于 44×44，Android 返回键可关闭 Sheet。
