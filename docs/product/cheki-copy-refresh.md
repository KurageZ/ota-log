# 电子切册文案调整记录

> 状态：历史变更记录（已实施）；当前筛选文案以 [筛选规范](cheki-filter-refactor.md) 为准
> 日期：2026-08-13  
> 范围：电子切册主页面、筛选与显示选项

## 改动内容

- 搜索提示明确为「搜索艺人、活动或备注」。
- 图片状态统一为「无图片 / 部分有图 / 全部有图」。
- 筛选摘要使用自然语序，例如「2 位艺人」「2 种规格」；「已有备注」简化为「有备注」。
- 日期子选择器使用「完成」，与最终提交筛选的「应用」区分。
- 空状态和无结果状态根据「相册 / 记录」分别显示，并只保留「添加记录」主操作。
- 「视图设置」统一改为「显示选项」，浏览模式使用「相册 / 记录」。
- 删除确认说明不可恢复；收藏失败提示改为「失败对象 + 下一步」。
- 可见数量统一在数字与「张」之间留空格，并同步无障碍名称。

## 保留术语

- 页面与导航继续使用「电子切册 / 切册」。
- 单个实体使用「拍立得」，一组拍摄或购买内容使用「拍立得记录」。
- 保留用户熟悉的「单推」「背签」等领域词，不使用 `Item`、`Record` 等内部模型名。

后续新增文案遵循 `docs/product/ui-ux.md` 的「文案规范」。
