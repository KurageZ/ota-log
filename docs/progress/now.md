# 当前进度

最近更新：2026-08-26

## 当前焦点

- 当前数据库版本为 Migration v23；v22 引入可选艺人类型、未设置记录的普通所属和个人到团体的时间履历，v23 新增 6 个固定拍立得小组件分组及其手动/筛选关系表。
- 团体活动只在场次日期与个人在团区间相交时归因给个人；拍立得保持直接关联，不沿所属关系归因。
- 场馆继续使用场次上的 `city` / `venue` 文本；出演者不引入角色；活动只保留一个 `actual_expense`，不保存票种和币种。
- 活动创建、编辑和详情页已接入多场次、实际支出与结构化时间表；表单可按场次编辑扁平条目，详情页按场次展示并提供独立日历入口。
- 所有活动页的搜索与筛选已适配活动 v2 聚合：搜索覆盖场次、时间表和归因艺人，日期按场次区间相交，筛选采用草稿应用机制与同类 OR 语义。
- 场馆继续使用输入部分名称匹配历史场馆，不提供沿用上一次地点。
- 拍立得数据模型为 Record / Item / Image，单价与规格归属 Item，Record 总价由 Item 单价求和。
- Migration v17 直接从已提交的 v16 `cheki` / `cheki_manual_entries` 升级，并保持数量、图片和旧价格语义。
- 规格已调整为纯物理参数：只参与筛选、Record 详情规格分布和全屏详情标签，不再派生展示比例；缩略图按图片自身比例完整显示，展示方式由设置页「外观与显示 → 拍立得展示方式」（拍立得 / 正方形网格）控制，影响艺人详情、活动详情、拍立得记录详情与电子切册，全屏查看器不受影响。
- 电子切册相册选项改为「拍立得 / 正方形网格」：分别对应三寸竖版外框与圆角卡片；页内切换只影响本次会话，不写入持久化。
- 新增图片按比例自动推断规格方向（宽 > 高为三寸横版，否则为三寸竖版，默认三寸，不推断方形）；Record 表单不再提供批量规格选择，方形与五寸在单张编辑中手动设置。
- 电子切册使用“相册 / 记录”浏览模式与独立筛选草稿，相册支持分组、排序、大小和比例，记录按月分区，待完成双平台与深浅色人工验收。
- 电子切册深链已按条件语义选择模式：日期与艺人等通用条件适配用户上次模式，精确活动等专属条件强制对应模式，且入口参数只消费一次。
- 新数据库不再写入第三方预置艺人。
- 过渡版本仅在临时 staging 目录中注入旧头像资源，用于把升级用户的 `preset://` 头像永久化到 Documents。
- 完整备份前再次检查旧头像迁移结果，避免生成缺少艺人头像的不完整备份。
- 外部数据导入已改为有限支持：不再按来源版本号硬拒绝，改为执行真实结构、SQL 与数据预检；当前可尝试读取兼容的 `.chekiroku` 备份，并明确提示不会导入的扩展数据。
- iOS 拍立得分组小组件主体实现已落地：包含 6 个固定槽位、手动/条件来源、SQLite 与完整备份、共享选择器、排序编辑和按槽位生成的共享 timeline；轮播改为整点/半点更新，小号逐张推进、中号整组三张推进。除暂不处理的休眠手动成员编辑保留问题外，代码评审问题已修复，仍需完成真机验收。
