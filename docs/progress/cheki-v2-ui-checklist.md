# 拍立得新版 UI 验收清单

> 用途：逐项检查本轮新增和修改的拍立得功能。发现问题时，在对应条目后记录平台、操作步骤和截图。
>
> 最近更新：2026-08-04

## 验收准备

- [ ] 准备一位已有拍立得价格记录的艺人。
- [ ] 准备一个与测试日期相同的活动。
- [ ] 准备至少 4 张测试图片，其中 1 张适合作为背面。
- [ ] 分别记录 iOS / Android、浅色 / 深色的检查结果。

## P0：新增拍立得记录

### 图片和数量

- [ ] 打开新建页时，图片区域显示在数量之前。
- [ ] 不添加图片，只填写数量，也能正常保存。
- [ ] 打开新建页时数量默认显示为 1，不显示“选图后自动填写”。
- [ ] 选择的图片数超过当前数量时，数量自动提高到所需值。
- [ ] 先填写较小数量，再选择更多图片，数量自动增加。
- [ ] 移除刚选择的图片后，数量保持不变。
- [ ] 可以分多次打开相册继续选择图片。
- [ ] 相册单次最多可选择 20 张图片。
- [ ] 可以使用相机添加一张图片。
- [ ] 图片导入过程中有明确的进行中状态，不能重复触发导入。
- [ ] 部分图片导入失败时，成功的图片仍然保留，并显示清楚的错误提示。

### 艺人、日期和活动

- [ ] 未选择艺人且未点击“暂不关联艺人”时，不能保存。
- [ ] 点击“暂不关联艺人”后，可以继续保存。
- [ ] 选择艺人后，能自动填入该艺人上次使用的单价。
- [ ] 手动修改价格后重新选择艺人，不会覆盖本次输入。
- [ ] 输入完整日期后，会出现同日活动候选。
- [ ] 活动只在主动点击后关联，不会自动选择第一项。
- [ ] 清除或修改日期后，活动候选正确更新。

### 价格和保存

- [ ] 输入单价后，总价随数量正确计算。
- [ ] 单价留空或为 0 时可以保存，并按 0 处理。
- [ ] 单价只接受大于或等于 0 的整数。
- [ ] 非法数量或价格会显示清楚的提示。
- [ ] 保存后进入记录详情，数量、总价、艺人、日期和活动均正确。
- [ ] 保存过程中不能重复点击保存。
- [ ] 有未保存修改时返回，会出现放弃确认。

## P0：拍立得记录详情

- [ ] 顶部正确显示艺人、日期、数量、已添加数量和总价。
- [ ] 详情页不显示单价。
- [ ] 点击艺人和活动可以进入对应详情页。
- [ ] 图片按各自设置的比例显示，没有明显拉伸。
- [ ] 有备注的图片显示备注标识。
- [ ] 已收藏的图片显示红色心形。
- [ ] 有正反面的图片显示“双面”标识。
- [ ] 没有图片时显示“可以之后再添加”的空状态。
- [ ] “继续添加图片”可以进入记录编辑页。
- [ ] 图片已经补满时仍可继续添加，保存后数量正确增加。
- [ ] 记录备注显示正确。
- [ ] 删除整条记录前会二次确认，取消后数据不变。

## P0：编辑拍立得记录

- [ ] 原有数量、艺人、日期、活动、价格和备注正确回填。
- [ ] 可以继续添加多张图片。
- [ ] 可以把已有图片标记为移除。
- [ ] 可以撤销待移除状态。
- [ ] 取消编辑后，新增和待移除图片均不生效。
- [ ] 保存后，新增和移除结果同时生效。
- [ ] 移除已有 Item 后，记录数量同步减少。
- [ ] 数量不能小于保存后仍保留的拍立得数量。
- [ ] 保存失败时，原有内容不会只修改一部分。
- [ ] 有未保存修改时返回，会出现放弃确认。

## P0：查看和编辑单张拍立得

### 全屏查看

- [ ] 点击缩略图可以打开全屏查看。
- [ ] 正面和背面都存在时，可以依次查看两面。
- [ ] 当前显示的是正面还是背面，信息清楚。
- [ ] 收藏按钮可以收藏和取消收藏。
- [ ] 收藏状态立即更新，关闭后缩略图状态一致。
- [ ] 编辑按钮进入当前这张拍立得的编辑页。
- [ ] 删除按钮删除整张拍立得，而不是只删除当前一面。
- [ ] 取消删除后，拍立得仍然存在。

### 正反面

- [ ] 只有正面时，可以添加背面。
- [ ] 只有背面时，可以添加正面。
- [ ] 可以分别替换正面和背面。
- [ ] 两面都存在时，只能移除背面，正面不显示移除操作。
- [ ] 只有背面时，可以移除最后一面并保留无图 Item。
- [ ] 取消编辑后，新选择或待移除的图片不生效。
- [ ] 保存后，详情页和全屏查看中的正反面均正确更新。

### 收藏、规格和备注

- [ ] “收藏这张拍立得”开关正确回填。
- [ ] 在编辑页修改收藏后，详情页心形状态正确。
- [ ] “三寸竖版”“三寸横版”“五寸竖版”“五寸横版”和“方形”显示正确。
- [ ] 五种受控规格可以保存，并在详情与全屏详情中正确显示；页面不提供自定义规格入口。
- [ ] 修改规格不会改变原图片内容。
- [ ] 单张备注可以新增、修改和清空。
- [ ] 单张备注在全屏详情中正确显示。

### 删除单张

- [ ] 从编辑页删除单张前会二次确认。
- [ ] 删除后返回所属记录详情。
- [ ] 删除后该张正反面和收藏状态一起消失。
- [ ] 删除后记录总数量同步减少；删除最后一张时整条 Record 消失。
- [ ] 删除失败时显示提示，原数据仍然存在。

## P1：电子切册记录模式

- [ ] 原“时间”模式已显示为“记录”。
- [ ] 记录模式按业务日期分月显示，未填写日期的记录固定放在最后。
- [ ] 每次拍摄或购买显示为一个独立条目。
- [ ] 每条记录固定显示艺人、含星期的日期、单行活动名称；总张数位于右侧，不展示价格或图片状态摘要。
- [ ] 点击条目进入对应记录详情。
- [ ] 搜索可以匹配艺人、活动和备注。
- [ ] 艺人、活动、年份、月份等筛选结果正确。
- [ ] 已生效筛选可以单独清除。
- [ ] 最新在前和最早在前排序正确。
- [ ] 升级前使用“时间”模式的用户会自动切换到“记录”模式。
- [ ] 空列表和无搜索结果时，提示与下一步操作清楚。

## P1：视觉和操作体验

- [ ] 所有新增页面在浅色模式下文字、图标和边框清楚。
- [ ] 所有新增页面在深色模式下文字、图标和边框清楚。
- [ ] 小屏设备没有文字截断、按钮重叠或横向溢出。
- [ ] 横版和自定义比例不会遮挡相邻图片或操作按钮。
- [ ] 键盘不会遮住数量、价格、自定义比例和备注输入框。
- [ ] 所有主要按钮的点击区域足够大。
- [ ] 收藏、删除、移除等状态不只依赖颜色表达。
- [ ] 加载、保存和图片导入时不会出现重复提交。
- [ ] 页面中的文案面向用户，不出现数据表、文件路径或内部模型名称。

## P1：回归检查

- [ ] 从活动详情新建拍立得时，活动和日期正确带入。
- [ ] 从艺人详情新建拍立得时，艺人正确带入。
- [ ] 旧有拍立得记录仍可查看。
- [ ] 旧有图片仍能正常加载。
- [ ] 备份后恢复，记录、正反面、收藏、比例和备注均保留。
- [ ] 清理未使用图片不会删除仍在使用的正面或背面图片。
