ota log 技术支持

如果你在使用 ota log 时遇到问题，可以在这里获取帮助。

联系开发者

请通过 GitHub Issues 提交问题。为了便于排查，建议说明设备系统、ota log 版本、操作步骤和出现的现象。

请勿提交个人记录、微博登录信息、备份文件或其他敏感内容。

提交问题

常见问题

  • 数据默认保存在当前设备中，不会自动同步到其他设备。
  • 更换设备前，请在“设置 → 备份和恢复”中生成并保存完整备份。
  • 相机、照片或日历功能不可用时，请检查系统设置中的 App 权限。
  • 微博或 iEvent 导入依赖对应第三方服务，服务异常时可以稍后重试。

隐私

关于本地存储、系统权限和第三方服务的说明，请查看 ota log 隐私政策。
