# iPad 自适应布局进度

最近更新：2026-09-03

本文件保留阶段记录；当前范围以 用户当前请求及明确指定的 issue为准，未勾选条目不代表自动执行授权。

## 目标

让 ota-log 在 iPad（含 Split View、Stage Manager）下可用：支持横屏，界面随窗口宽度切换布局，不按设备型号判断。

## 窗口模式（阶段一已建立）

- Compact：宽度 < 680，保持现有手机单列。
- Regular：680–959，居中内容或轻量双栏。
- Wide：≥ 960，启用主从布局和多列仪表盘。

阈值常量集中在 `src/utils/windowMode.ts`，真机验证后可调整。

## 统一容器（阶段一已建立）

- `ReadingContainer`：最大宽度 680，阅读/表单页使用。
- `DashboardContainer`：最大宽度 1120，仪表盘页使用。
- gutter：Compact 16 / Regular 24 / Wide 32，由容器统一提供，页面不再硬编码水平边距。
- 图表等需要精确宽度的子组件用 `getAdaptiveContentWidth()` 计算，避免与容器实际布局不一致。

已接入：首页、统计、我的、设置（Wide 使用仪表盘容器）、活动列表（阅读）。

## iPad 导航（阶段一已建立）

- iOS `NativeTabs` 显式使用系统 Tab Bar，避免 adaptable sidebar 在 iPad 横屏下浮在内容上方。
- 五个主入口不变：首页、日历、切册、统计、我的。
- 不按窗口宽度重建导航器，旋转与 Split View 不重置导航状态。

## 验收清单

- iPhone 窄窗口与现有手机布局一致（无回归）。
- iPad 横竖屏均可旋转，Split View 1/2、1/3 宽度下布局正确。
- 浅色/深色模式下文字、卡片、按钮无溢出遮挡。
- iPad 横屏下不出现左侧导航遮挡，底部 Tab 在各窗口宽度下均可用。
- Wide 活动/艺人列表点击不 Push，右侧详情切换且选中高亮同步；缩窄到 Regular / Compact 后点击恢复 Push。
- Wide 右栏内的活动分享、活动/艺人编辑与删除后的选中项回退正常。
