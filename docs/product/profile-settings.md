# 我的、设置与关于

页面细节由 UI/UX 总文档迁入；跨页面规则见 [UI/UX](ui-ux.md)，产品定位见 [PRODUCT.md](../../PRODUCT.md)，术语见 [CONTEXT.md](../../CONTEXT.md)。仅在相关任务改变这些行为时更新。

### 我的页 IA

`Profile` 是身份和常用入口页，不承载复杂设置表单。当前结构：

1. 身份卡：头像、昵称、编辑入口、活动/完成/收藏/拍立得统计。
2. 单推：已设置时进入艺人详情，未设置时进入 `/settings/oshi`。
3. 功能：所有活动、艺人管理、重要日期、工具箱。
4. 更多：设置、帮助、关于。

Profile 上不直接放备份、清理、微博登录、主题、日历默认视图等操作。

我的页右上角提供齿轮设置 icon，点击进入 `/settings`，与「更多 → 设置」菜单入口一致。

宽屏布局按窗口宽度切换：Wide（≥ 960）使用最大宽度 1120 的仪表盘容器，身份卡改为横向摘要，左侧集中头像、昵称和单推，右侧横排活动/完成/收藏/拍立得统计；「功能」与「更多」在摘要卡下方等宽并排。Compact / Regular 保持身份卡、功能、更多依次排列的单列结构，不因设备型号切换。

### 设置页 IA

`/settings` 是单页设置中心。当前分组：

1. **个人**：个人资料、单推设置。
2. **外观与显示**：外观（子页，含显示模式与主题色）、拍立得展示方式（子页，拍立得 / 正方形网格）。
3. **偏好**：功能（子页，含切册/统计默认视图与出演者确认）、日历（子页，周起始日与月视图展示）。
4. **小组件**（仅 iOS）：拍立得回忆的展示艺人设置。
5. **数据管理**：存储空间（含清理未使用图片）、备份和恢复（子页，含生成备份数据、保存到本地、恢复备份）、艺人类型转换。
6. **高级**（仅 dev）：移除孤立艺人、清空所有数据。正式包不显示该分组。

首页自定义（`/settings/home`）与统计自定义（`/settings/stats`）属于页面级内容自定义，不在设置中心列出，分别从首页与统计页右上角的设置入口进入。

设置页以分组承载入口，避免单页过长：外观（`/settings/appearance`，显示模式与主题色合并）、功能（`/settings/features`，默认视图与出演者确认合并）、日历（`/settings/calendar`，周起始日与月视图展示）与拍立得展示方式（`/settings/cheki-display`，拍立得 / 正方形网格）作为独立子页，入口均显示静态副文案、不显示当前值，点击进入查看。子页内每个功能一个 section，选项直接展示为单选卡片，不做折叠展开。仅备份三件套保留状态语义色（导出蓝 / 保存绿 / 恢复橙）。

设置页不使用大标题（`headerLargeTitle`），与 Tab 层级保持一致即可。

设置中心在 Wide（≥ 960）使用两列分组：左列为个人、外观与显示、小组件（iOS），右列为偏好、数据管理、高级（仅 dev）。每个 section 作为完整单元，不拆分 MenuCard 内的菜单行；Compact / Regular 继续使用现有分组顺序的单列阅读容器。设置子页仍通过 Stack Push 打开，不在本阶段改为主从详情。

## 页面呈现

### Profile

- 顶部身份卡是强品牌块，使用 `accentStrong` 或对应主题强色。
- 统计数字白色 24/900，说明文字 11，分隔线为白色低透明度。
- 单推卡已设置时显示 `OshiAvatar` 和 `OshiBadge`；未设置时显示心形 icon 和「设置单推」。
- 低频维护操作不回到 Profile。

### Settings

- 保持单页、分组、可展开。
- 显示模式、主题色、日历默认视图使用 radio 选择。
- 「出演者确认」使用三态 radio：默认「每次询问」；「仅在可能匹配时询问」只展示可能对应本地艺人库的候选；「不再询问」保留自动精准匹配结果并跳过其他候选。确认页候选默认不选择，提供「全选 / 取消全选」。
- 首页自定义从首页右上角设置 icon 进入 `/settings/home`，不在设置中心列出。
- 统计自定义从统计页右上角设置 icon 进入 `/settings/stats`，不在设置中心列出；配置行只显示 section 名称和拖拽手柄，不使用业务 icon 或说明副文案。
- iOS 的「小组件」分区进入 `/settings/widget`，管理 6 个固定拍立得分组槽位。槽位编辑页按「分组名称 / 内容来源 / 来源配置 / 当前内容」组织；手动与条件筛选使用带业务 icon 的大模式按钮，模式用途说明紧跟按钮并随选择切换，具体选择入口使用带 chevron 的标准菜单操作行。手动模式直接在当前内容网格排序，仅首次显示一次拖动教学；手动多选页把已选数量、当前结果数量和「全选 / 取消全选」合并为不换行的单行选择工具栏，搜索或筛选生效时批量操作只作用于当前结果，保留结果之外的已有选择；全选按当前顺序截断到 48 张。筛选模式在操作行摘要条件，并在当前页面以与手动模式相同的「中」密度完整展示最多 48 张结果。筛选面板遵守草稿 / 应用语义，艺人候选通过共享选择器让单推艺人稳定排在首位，并继续使用个人类型优先的共享排序规范。
- 备份状态用 MenuItem badge 表达，允许 spinner、已完成、重试、可保存等状态。
- 备份和恢复子页顶部有使用说明卡片，简述「生成备份数据 → 保存到本地 → 恢复备份」流程，并提示恢复会覆盖当前数据。
- 微博相关入口统一命名为「登录微博」和「艺人导入」。

### About

- 使用 `SectionLabel + MenuCard + MenuItem` 的结构语言。
- 页首展示当前版本标识（如 `v2.0 Beta 1`），内部命名与 iOS 规范版本号分离。
- 「隐私与数据」入口进入 `/privacy`，按本地存储、权限用途、联网与第三方服务、控制与删除四个分组说明当前数据处理方式，并提供公开隐私政策网页入口。
- 不提供应用内版本更新记录，版本说明由外部 changelog 与 TestFlight release notes 提供。
- 帮助文案要短，不做长篇说明。
