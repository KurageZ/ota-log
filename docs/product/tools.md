# 工具箱与外部数据导入

页面细节由 UI/UX 总文档迁入；跨页面规则见 [UI/UX](ui-ux.md)，产品定位见 [PRODUCT.md](../../PRODUCT.md)，术语见 [CONTEXT.md](../../CONTEXT.md)。仅在相关任务改变这些行为时更新。

### 工具箱

`/tools` 承载低频但独立的工具入口。当前包含 iOS / Android「拍立得贴纸相机」、外部数据导入、微博关注导入与登录微博（均归入「数据」分组），以及 Mix&Call（查 call 本 · 找 mix · 对公演 / EP / 单曲）、「推活日记」外部网站。新增工具时优先放这里；我的页「功能」区只保留工具箱总入口。

拍立得贴纸相机支持 iOS 与 Android，使用 App 内电子切册的正面照片作为贴纸来源，不请求系统相册读取权限。Android 相机使用 4:3 预览，拍摄结果在合成前按 3:4 取景框居中裁切，确保预览与导出构图一致。贴纸相机与小组件分组共用 `ChekiPickerScreen` 拍立得多选页面：按切册页「小」密度、以「拍立得」方式呈现，网格宽度随屏幕自适应；搜索覆盖艺人、活动、日期、记录备注与单张备注，筛选复用相册模式的日期、艺人、规格、关联活动、备注、收藏和背签条件。搜索或筛选不得清除已选内容或改变点选顺序。页面使用标准 Stack Header，iOS 的「取消 / 完成」通过原生 Toolbar 呈现，选择数量放在内容区而不拼入导航按钮。贴纸相机最多选择 9 张并用数字标记点选顺序，达到上限后未选项目置灰。

贴纸相机含五寸横版时按相纸尺寸统一缩放：三寸竖版为 54 × 86，五寸横版为 108 × 86，五寸占两个无间距宽度单位但仍计一张。混排按占位分配扇形位置，保留选择顺序，按旋转后的边界整组缩小；图片按原比例完整适配规格区域。五寸竖版暂不作专项处理，无五寸横版时沿用原布局。贴纸不支持移动、缩放或手势旋转。单张固定在画面左下；多张以画面底部中央为圆心形成扇形，张角按画布宽度自适应、尽量让扇形铺满整个画面宽度（两张时向中间靠拢），拍立得中心连线沿圆弧排列（中间最高、两侧对称下沉），第一张位于左后方、最后一张位于右前方。每层贴纸都使用阴影，预览和最终 Skia 合成必须共用同一布局结果。相机页的「更换贴纸」重新打开选择器并保留当前选择，只有再次确认后才整组替换；结果页以「添加 App 水印」开关替代分辨率展示，默认开启、可关闭，开启后在图片中间最下方合成半透明 App 水印（预览与保存共用同一张图），并保留保存/分享与底部「重新拍摄」。


## 外部数据导入


- `/tools/chekiroku-import` 按「选择文件 / 确认导入 / 导入结果」组织，不在同一长页面中追加完成状态。
- 入口和页面使用「外部数据导入」等泛化文案；当前可尝试读取兼容的 `.chekiroku` 备份文件，并明确标注「有限支持」。页面不使用第三方 Logo、图标或官方兼容措辞。
- 首屏说明使用无序要点列表，分别说明本地处理、预检与结果提示、当前文件格式和独立运行声明；不在引导句中强调数据来自其他应用。
- 页面说明文件仅在本机处理，且本工具独立运行，不代表与任何第三方存在关联、授权或背书。未来支持 CSV 时再增加对应格式选项，未实现前不展示虚假的支持承诺。
- 确认页首先展示将导入的拍立得总数，其次展示记录、成员和团体数量；不向用户展示数据库版本、源表行数、Item、表名或字段名。
- 艺人处理区分别说明新增与匹配已有的成员、团体数量，并允许从 Bottom Sheet 查看完整名单。匹配到外部数据中已收藏的成员时会把已有艺人同步设为收藏，必须在「需要留意」和最终确认中说明影响。
- 外部数据标记为同一人的成员统一称为「重复成员」；每组都必须由用户明确选择分开保留或合并目标，不能静默使用默认值。多组待处理时允许主动选择「全部分开保留」。
- 头像、日期、活动、会场、类别、隐藏状态、排序、纪念日和外部数据中的未知扩展数据等兼容性差异归入「需要留意」，使用结果导向的用户文案，不展示记录 ID 或导入器诊断文本；任何已识别但不会导入的数据都不能静默丢弃。
- 页面底部使用固定操作栏，按钮写明实际导入张数；存在未处理的重复成员或无法导入的记录时，按钮说明阻塞原因并保持不可用。
- 页面只承诺不会删除或替换现有记录，不使用「不会覆盖现有数据」等会掩盖收藏状态同步的绝对表述。
- 开始写入前使用简短确认 Bottom Sheet，复述新增/匹配艺人数量、已有艺人收藏状态同步和重复导入风险。导入事务成功后展示独立结果页，主操作进入电子切册的记录模式，次操作返回工具箱；失败时保留当前预览和用户选择，允许直接重试。
