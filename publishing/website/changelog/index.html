OTA LOG / CHANGELOG

更新日志

在这里看看 ota log 的新功能、体验优化与问题修复。

以下为正式版本的主要更新，具体可用版本以各平台下载入口为准。

v2.1.0

2026-10-13最新记录

新增

  • 支持从普通网页链接提取并解析活动公告。
  • 支持按活动快速录入拍立得，批量选择成员并复用最近单价。
  • 工具箱新增「推活日记」入口。

优化

  • 优化底部面板、筛选和日期选择的操作体验。
  • 小组件活动筛选支持按名称和日期搜索，也可以移除已选活动。

修复

  • 修复 Android 短页面底部导航栏隐藏后无法恢复的问题。
  • 修正 Mix&Call 网站地址与说明。

v2.0.2

2026-09-14

新增

  • iOS 拍立得记录表单新增扫描入口。
  • 切册支持配置展示布局并预览，五寸横版照片可跨两格展示。

优化与修复

  • 修复拍立得选择器拖拽排序和拖拽状态残留的问题。
  • 修正贴纸相机混排不同规格拍立得的相对尺寸，让预览与导出布局一致。
  • 优化横版拍立得小组件的布局与间距。

v2.0.1

2026-09-07

修复

  • 修复开发模式下新手引导完成后仍会重复显示的问题。
  • 修复 Android 新建活动和艺人时顶部取消、保存按钮缺失的问题。

v2.0.0

2026-09-04

新增

  • iOS 实时活动：在锁屏与灵动岛查看活动阶段、时间表和倒计时。
  • 适配 iPad 宽屏布局，覆盖首页、日历、统计、艺人和活动等页面。
  • 保存、删除和操作失败时提供触觉反馈。
  • 艺人缺少头像时可用名称生成头像，支持根据名称与简称推荐所属关系。

优化

  • 优化首页艺人选择和活动标签。
  • 优化实时活动的开场前信息和时间表展示，支持关闭后重新开启。

修复

  • 修复 iOS 艺人背景色、开关颜色同步和贴纸相机滤镜问题。
  • 修复恢复备份后旧媒体文件未清理的问题。
  • 修复月份汇总未在月份视图中打开的问题。
  • 修复 Android 新手引导可能被意外跳过的问题。
