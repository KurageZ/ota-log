# 当前进度

最近更新：2026-08-27

## 当前目标

项目进入正式版发布准备阶段。除新手引导、现有小组件与实时活动优化及发布必需内容外，停止增加新功能，优先完成现有功能收尾、商店材料、质量验证与正式版发布。

## 范围约束

- 不新增非发布必需的功能，不扩大现有需求范围。
- 不进行无关重构、数据库结构调整或大规模 UI 重绘。
- 新发现的问题按是否阻塞发布分级：阻塞项在本版本修复，其余记录后延期。
- 本阶段只接受新手引导、「下一场活动」小组件、「活动 + 时间表」实时活动、App Store 上架要求、稳定性和合规性相关改动。

## 当前任务

### 1. 新手引导

- 为首次使用补充简短引导，说明活动、艺人、切册和本地数据的核心使用方式。
- 支持跳过引导，并在设置中提供重新查看入口。
- 检查文案、权限请求时机、浅色/深色模式和小屏设备显示。
- 确保引导不会阻塞已有用户升级或正常进入 App。

### 2. 小组件与实时活动优化

- 优化「下一场活动」小组件的信息层级、布局和可读性。
- 检查小组件的数据刷新、活动过期切换、空状态和深链跳转。
- 优化「活动 + 时间表」实时活动，清晰展示活动状态、当前时间表项目和下一项安排。
- 在真机验证锁屏、灵动岛及不同活动状态下的展示和更新行为。

### 3. App Store 上架内容

- 完成应用名称、副标题、简介、关键词、分类、版本说明和版权信息。
- 准备符合当前正式版界面的商店截图，并检查截图中无测试数据、调试信息或过期 UI。
- 准备隐私政策 URL、支持 URL、App 隐私申报、年龄分级和出口合规信息。
- 补齐 App Review 联系信息、审核备注，以及审核人员理解本地优先数据模型所需的说明。
- 核对图标、启动画面、Bundle ID、版本号、构建号、上架地区和发布方式。

### 4. 正式版验证

- 运行 TypeScript、Jest 和 Expo Doctor 基线检查。
- 在 iOS / Android、浅色 / 深色模式下完成核心流程回归：新手引导、活动、艺人、切册、统计、备份恢复和设置。
- 重点验证现有高风险流程：旧库升级、旧头像迁移、完整备份恢复、拍立得展示与贴纸相机、iOS 小组件与实时活动。
- 验证全新安装不生成预置艺人，升级安装不丢失数据或图片。
- 使用生产配置生成候选构建，先完成 TestFlight / 内部测试，再处理阻塞问题并生成最终构建。

### 5. 发布

- 按 `docs/workflows/release.md` 同步 `package.json`、`app.json`、`CHANGELOG.md` 和 `app/about.tsx`。
- 确认生产凭据、App Store Connect 应用记录和提交流程可用。
- 提交审核前复核商店材料、隐私申报、候选构建和发布说明。
- 审核通过后发布正式版，并记录版本号、tag 和已知非阻塞问题。

## 发布完成标准

- 新手引导可用，且不影响升级用户和日常使用。
- 「下一场活动」小组件和「活动 + 时间表」实时活动通过真机验证，展示、刷新和状态切换符合预期。
- App Store 必填内容、截图、隐私与审核信息完整且与实际行为一致。
- 核心流程无阻塞问题，迁移、备份恢复和生产构建验证通过。
- TypeScript、Jest、Expo Doctor 及必要的真机测试通过。
- 正式版通过审核并可在 App Store 下载。

## 延期到发布后

- 所有非发布必需的新功能和体验扩展。
- 不影响核心流程的视觉优化、重构和低优先级缺陷。
- 需要扩大数据模型或新增 migration 的需求，除非其修复发布阻塞问题。
